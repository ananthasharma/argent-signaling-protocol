# Security Policy

ASP is intended for AI governance and quality signaling. It should not be treated as a security boundary by itself.

## Reporting Issues

If you identify a vulnerability or misuse pattern, please open a private security advisory or contact the repository maintainer.

## Important Limitations

ASP signals are auditable proxies. They do not guarantee truth, safety, legality, or correctness.

Deployments should combine ASP with:

- access controls,
- human review,
- domain-specific validation,
- retrieval quality checks,
- model-risk controls,
- logging and monitoring,
- policy enforcement.
