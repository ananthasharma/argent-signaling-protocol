# Contributing

Thank you for your interest in the Argent Signaling Protocol.

This repository is currently focused on:

- protocol documentation,
- reference implementation,
- telemetry schemas,
- routing examples,
- governance-oriented use cases.

## Contribution Areas

Useful contributions include:

- improvements to protocol documentation,
- additional signal estimators,
- examples for agent frameworks,
- telemetry adapters,
- benchmark reproduction scripts,
- diagrams,
- test cases,
- governance and compliance mappings.

## Design Principles

Contributions should preserve ASP's core design goals:

- auditability,
- compactness,
- deterministic routing,
- model-agnostic operation,
- transparent telemetry,
- clear distinction between repair and containment.

## Pull Requests

Please include:

- a clear description of the change,
- rationale,
- test coverage where applicable,
- documentation updates for user-facing changes.
